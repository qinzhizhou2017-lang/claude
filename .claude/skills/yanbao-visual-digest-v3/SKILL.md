## 一、内容与数据纪律（原样保留，不许简化）

1. **逐份处理**：抽完一份原文就写完那一份，再动下一份。不要全读完再统一写。
2. **每个数字留出处**：`<!--src: MS p24 表-->`；图上目测的标 `<!--src: MS p24 图/目测-->`；
   自己算的写成 `<!--src: 测算 = 88−60=28 kt，据 MS p6 表-->`。
3. **推论必须标记**：原文没有、你自己算的结论，正文里写"（本文测算）"。
4. **拿不准就说拿不准**：想不起确切出处，直接告诉我，不要补一个看起来合理的。
5. 不要把原文的限用水印邮箱写进产物。

## 二、版面美学规范

- **从"卡片堆叠"改成"编辑排版"**：每页填色/描边容器 ≤2 个，其余靠 1px 细线 + 小标签分组；
  删掉所有左侧色条；圆角只留两级（容器 8px、胶囊 999px）；表格只留三条线，表头不填色。
- **1 个强调色（金）+ 2 个语义色（涨绿/跌红）+ 中性灰阶**，强调色每页 ≤5 次，涨跌色只标真涨跌。
- **每页一个主角**（一张表／一组大数字／一张图／一句大引文），占视觉重量四成以上；
  每页留一处 ≥12mm 的呼吸；**连续三页不许同构**。
- 字号：正文 19.5px / h1 52px / h2.sec 34px / h3 22px / 表格 16px。**任何情况下不许降字号。**
- 图表：能画图就别堆表格；纯手写 SVG/CSS，不引外部库；**不要图例、不要网格线、不要外框**；
  每张图配一句 cap 写"这张图想说什么"。
- ❌ emoji ／ 渐变背景 ／ 多重投影卡 ／ 圆角+浅灰底+左色条 ／ 正文居中 ／ 三种以上强调色
  ／ 赋能·闭环·抓手·护城河这类词。
- **第一份的第 1 页写完，先导一张 PNG 给我确认版式**，再往下批量写（只确认这一次）。

## 三、每份写完立刻自查

**数据四项**：A 抄录（数字/单位/量级/同比环比）｜B 图表读数（标"目测"的重新开图核）｜
C 归属（牛熊基串没串、FY vs CY、一致预期 vs 机构自己预测、观点安错人）｜D 推论有没有标"（本文测算）"｜
**E 分组数字与总盘对账**（8.26 实测：全 PASS 之后仍把"8 买入"写成"7 买入"，总盘本可倒推出矛盾）。

**美学六项**（缩到 25% 眯眼看）：盒子数 >2？金色 >5 次？三秒说不出主角？没有 ≥12mm 呼吸？
25% 下认不出三层结构？和前一页长得一样？

⚠ 不要回我"版式已优化"。直接给每页的：盒子数／金色次数／主角是什么／呼吸区在哪。

## 四、全部写完后跑机器回查

数字全抽出来 → 去逗号小数点归一化 → grep 抽取的正文 txt。**只列追不到的**，分类：
图表读数（正常）／单位换算假阴性（正常）／日期格式（正常）／**真的对不上（必须改）**。

⚠ **不要回我"已逐项核对，数据无误"。** 直接给清单；一条都没有就说"回查 N 个数字，无待核项"。

扫描件（无文本层）时 grep 全部失效 → 改走隔离交叉验证（另起一个看不到制作过程的核查任务对照原 PDF 逐项核）。

## 五、交付

```
python3 scripts/render_pdf.py 成品.html 成品.pdf --png 拼版.png
python3 scripts/verify_pdf.py 成品.pdf --pages X --cover 1
python3 scripts/coverage_report.py 成品.html --doc MS:1-8/51 --pages MS=2
```

- 溢出：每页底部 room > 15px，**且呼吸区还在**。处理优先级：**删内容 → 挂收紧类 → 永远不降字号**。
- 留白：`verify_pdf.py` 报 ≥14mm 的空隙要修（回原文捞真内容 > 放大组件一档 > 给留白找归属）。
- 覆盖报数**只报数不判定**，尤其"前三页占比"不是门禁。
- 交付说明里给四块：大纲（做成什么样了）／覆盖报数／**未引用正文页逐页交代**／待核清单。
- **未引用正文页逐页交代（2026-09-10 加，只管新的，过往不追溯）**：把 coverage_report 打印的
  「未被引用的正文页」逐页写一句「这页是什么 / 为什么没用」。不设阈值不判 FAIL，它是**读没读过的证据**——
  没读过的页说不出它是什么。写不出来就回去读。正文全被引用就写「无未引用正文页」；披露/图册区不算。
- 原文 PDF 拷进工程目录 `原文/`（9.01 没存，现在已经回查不了原件了）。
