# 版面与密度（A4 分页版 · v3）

一句话方针：**从"卡片堆叠"改成"编辑排版"**——靠留白和细线分层，填色盒子只留给全页唯一的重点。

---

## 一、工程骨架（别重造）

固定页容器，不能靠自然分页：

```css
@page { size: A4; margin: 0 }
.page { width:210mm; height:296.6mm; padding:7mm 12mm 6mm; overflow:hidden; break-after:page }
```

配 `.pg-head` 页眉、`.pg-foot` 页脚（绝对定位 bottom:4mm，含 `03 / 08` 页码）、
分隔页 `.page.div`（深色 #111A26 + 金线）、三级收紧类 `.tight` / `.tighter` / `.tightest`。
打印 CSS 必须 `@media print{ .rv{opacity:1} }` 强制显影 + `print-color-adjust:exact` 保配色。

## 二、字号硬线（2026-08-07 用户打回过一版之后定的）

- 正文 / 列表 / 表格 **≥10px**（A4 版现行 10.3–11px），注释 **≥8.4px**
- **塞不下删内容，绝不缩字号**——任何情况下、任何理由
- 大字口径（N 页 PDF 变体）：body 19.5px / h2.sec 34px / 表格 16px / theme 段 17.5px
- 标题三档：h1 52px / h2.sec 34px / h3 22px
- 封面大标题字数**连标点一起数**：90px 一行 10 个全角格，行尾逗号也占一格（11 格必折行留孤字）

## 三、留白心法（最难看的失败模式在这）

**"四处漏风"**：`space-between` 把剩余空间摊成多段碎空隙。自查线：**相邻块空隙 ≈ 块自身高度即失败**。

- 封面用 hero 弹性居中结构（标题+副标+核心判断合一块，信息卡固定间距压底）
- 内页空隙大 → **不删留白、不塞废话**，按优先级回填：
  ① 回原报告捞真内容（首选，量最大）→ ② 全局放大组件一档（正文 +0.3px、行高 +0.05、padding +2–3px，
  只能吃 25–30mm/页）→ ③ 给剩余留白找结构归属
- 判定阈值（`verify_pdf.py` 内置）：**空隙 ≥14mm = 漏风必修 / 10–14mm = 偏松 / <10mm = OK**；
  封面豁免（hero 呼吸区 35–45mm 是设计）
- **漏风肉眼扫 PNG 抓不住**——回归测把此前已交付的作品全照出来了（8/10 页、10/13 页漏风的都有）
- **每页仍要留一处呼吸**：至少一段 ≥12mm 连续空白。塞满到 room=15px 不算过关，
  但呼吸区必须"有归属"（在结构上属于某一块），不是摊开的碎空隙

⚠️ **字符级删减不跨行 = 高度不变**。要减高度必须删掉整个元素（`<li>` / `<tr>` / `<div class="src">`）或收间距。

## 四、溢出校验循环

1. 浏览器打开 `file://`（重测带 `?v=N` 破缓存，否则量到旧快照）
2. 量每页"最后一个非绝对定位子元素的 bottom" vs 页脚 top = room
3. room < 0 → 按优先级：**删内容 → 挂收紧类 → 永远不降字号**
4. 目标 **room > 15px**；只剩 0–3px 的页在打印取整时有风险，补挂一级收紧类
5. room > 150px 的富余页：补一张图 / 加一条速览 / 补数字来源行，**不许拉字号**

## 五、容器纪律（最容易出 AI 味的地方）

- **每页填色 / 描边容器 ≤2 个**，其余裸排：一条 1px 细线 + 一个小标签就算一组
- **删掉所有左侧色条**（4px 金条、3px 金条）——最重的 AI 味套路，一眼看出是模板生成
- 数字卡改裸排：`border-top:1px` + 上下留白 + grid 对齐；不要四边框 / 浅灰底 / 圆角
- 圆角收敛两级：容器 8px、胶囊 999px，其余一律 0
- 表格拆掉外面的圆角盒子，只留三条线：表头下实线、行间极淡线、末行无线。表头不填色，不要斑马纹

## 六、色彩

- 结构固定：**1 个强调色（金）+ 2 个语义色（涨绿 / 跌红）+ 一条中性灰阶**，不要第四个颜色
- **强调色每页出现 ≤5 次**，只用于三件事：栏目序号/eyebrow、这页最重要的那一个数字、图表主序列
- 涨跌色只标真涨跌，不当装饰；建议配 ▲▼ 第二编码
- 纸不纯白（#FFF 页面、浅灰台面），墨不纯黑（#141D2A）
- oklch 三强调色共用同一档 L 和 C 只变色相：
  `--gold:oklch(.55 .11 75); --bull:oklch(.55 .11 165); --bear:oklch(.55 .11 25)`；中性色 chroma < 0.02
  （导出 PDF 后若色偏，回退现有 hex）

## 七、构图：设计感主要来自这里

- **每页一个主角**，四选一：一张表 / 一组大数字 / 一张图 / 一句大引文。主角占视觉重量四成以上
- 页内节奏"密—疏—密"，别让三块等高等密度的东西并排
- **连续三页不许同构**：第 N、N+1、N+2 页主角都是表格 → 换掉中间那页
- 分隔页保持深色，超大 mono 序号（`02 / 03`）当图形用
- 页眉页脚是仪表不是内容：小字、中性色、逐页位置完全一致，不加装饰
- 中英混排：数字/英文与中文之间留 0.25em；数字等宽 + tabular-nums + 右对齐 + 同列小数位统一；
  单位量级跟在数字后小一号轻一档（`<i>亿</i>`）
- 正文行宽 ≤34em（约 40 个中文字），用 max-width 收，不要靠加盒子收

## 八、图表（比堆表格值钱得多）

| 要说的事 | 用什么 |
|---|---|
| 占比 / 结构 | 100% 堆叠横条 |
| 两组对比 | 哑铃图 或 分组横条 |
| 时间序列 | 极简折线，只标首末点与极值 |
| 排名 | 降序横条 |

- **纯手写 SVG/CSS，不引任何外部库**（离线导出、矢量清晰、不掉图）；坐标别手算，用 `svg_chart.py` 类生成器
- 去掉默认三件套：**不要图例、不要网格线、不要图表外框**；数值标在条端/点旁，系列名标在图形上
- 坐标轴只留一条基线，辅助横线 ≤3 条且极淡
- 单序列中性灰打底，只把要强调的那根染金；多序列 ≤3 色
- 每张图配一句 `cap`，写"**这张图想说什么**"，不是"XX 走势图"
- 图上的数字同样受数据纪律约束，注释里照样标出处
- **哑铃图下降行必撞字**：模板锚定按"上升行"设计（旧值朝左、新值朝右＝朝外），下降行两标签变成朝内相对，
  会糊成一团。修法：下降行内联翻转锚定（旧值 `transform:none; padding-left`，新值 `translateX(-100%); padding-right`）

## 九、禁止清单

❌ emoji 当图标或项目符号　❌ 渐变背景（紫蓝/彩虹/玻璃拟态）　❌ 多重投影的悬浮卡
❌ 每块都是"圆角+浅灰底+左色条"　❌ 正文居中（只有封面和分隔页可居中）　❌ 三种以上强调色
❌ 满篇高亮　❌ 图例+网格线+边框的默认图表样式

## 十、缩到 25% 眯眼自检（每页六项）

- **E1 数盒子**：填色/描边容器 >2 → 拆掉最弱的
- **E2 数金色**：强调色 >5 次 → 收回中性色
- **E3 找主角**：三秒说不出主角 → 重排
- **E4 找呼吸**：有没有 ≥12mm 连续空白？没有 → **删内容**，不是压间距
- **E5 缩略可读**：25% 缩略图下还认得出标题/主角/脚注三层结构
- **E6 邻页对比**：和前一页并排，是不是长得一模一样

⚠️ 不要回复"版式已优化"。直接给每页的：盒子数 / 金色次数 / 主角是什么 / 呼吸区在哪。

## 十一、来源条与免责（模板级，v3 必改）

- 来源条印 **`正文 N 页（原报告 M 页，P.a–P.b 为图册/披露未纳入）`**，不要只印总页数
- 封面双标题：**英文原标题原文照抄**（不改写不缩写），中文大标题是提炼的传播标题
- 免责一行化：写明"第三方研报提炼 / 机构观点 / 非投资建议"；
  **不要把原文的限用水印邮箱写进产物**
- 二维码：显示尺寸 **360px**（320px 在"缩到手机屏 780px"档处于临界）；
  `image-rendering:crisp-edges` 会在缩放时丢模块，真码直接废——不要加

### THE PORT 角标（2026-09-10 用户确立；当天先做成单独一页被打回「太丑」，改成角标）

**成品最后一页的右下角放 THE PORT 角标**，单篇版、多页版、合订版一律适用。合订版尤其不能省：
原页照搬时那 N 页里没有任何本方标识。**不要单独开一页**——用户明确否掉过。

- 素材：`/Users/zhizhouqin/Claude Code/THE_PORT_微信二维码.png`（950×1296 的微信名片）。
  **裁成两块用**，比整张缩进角落清楚得多：
  logo 块 `crop(135,110,525,265)`（红 P 图标 + THE PORT 字标）、二维码块 `crop(125,335,825,1045)`。
  两块分别 base64 内嵌，不要外链路径。
- 版式：**必须走正常流，不要 `position:absolute`**。绝对定位会压在表格和正文上（实测压掉了一行目标价）。
  做法是把页尾免责段和角标包进一个 flex 行：
  ```css
  .tailrow{display:flex;align-items:flex-end;gap:20px;border-top:1px solid var(--hair);padding-top:9px}
  .tailrow .disc{flex:1;border-top:none;padding-top:0;margin-top:0}
  .portmark{display:flex;align-items:flex-end;gap:11px;flex:0 0 auto}
  .portmark .pm-t{text-align:right}      /* logo 图 + 「全球投行研报精选」+ 「微信扫码 · 每日研报精华」 */
  .portmark .pm-q{width:84px;height:84px}  /* 二维码 */
  ```
- **角标的高度由二维码决定，而免责段通常只有 60–70px，所以角标一定会把页面顶高。**
  末页本来就是排满的，**动笔前先量末页的 room**，不够就按 §四 的优先级删内容——
  实测这一次为了塞进 84px 的码，删掉了一条「加分项」里的数据点，并压短了免责段。
  **删了什么必须在交付说明里逐条讲清楚**，不能悄悄删。
- **尺寸与可扫性的取舍（要主动告诉用户，别替他决定）**：
  角标里的码约 **84px ≈ 22mm**。A4 打印出来能扫；但页面缩到手机屏 780px 宽时只剩约 82px，
  一个 45 模块的码只有不到 2px/模块，**手机截图基本扫不出**。
  想要手机可扫就得给码 360px（≈95mm），那个尺寸只能单开一页——而单开一页已被否。
  所以现状是：**角标是品牌标识，不是主要引流入口**。用户若哪天说"扫不出来"，改的是这个取舍，不是代码。
- ⚠ 这是微信**个人号加好友码，会过期**。隔一阵找用户重新要一张。
- ⚠ 机器验不了可扫性：微信码中心压着 logo，OpenCV 的 `QRCodeDetector` 对**源图和成品都**只测得到定位点、
  解不出内容。**不要回复"二维码已验证可扫"**——只报显示尺寸，真扫用手机。
