# 选材与主线（v3 · 流程第一步，不是可选读物）

> 这份文件在 8 月做出 24 件好作品时被模型自己 Read 过 9 次；8.28 与 9.01 两次没读——因为标准指令
> 自带了完整流程，把它挤出了阅读路径，于是产出退化成翻译。**SKILL.md §0 已把它写进必读，别再跳过。**

---

## 一、先算术，再谈品味

**"编辑感"不是文笔问题，是页预算与正文长度的比值问题。**

| 正文 : 成品 | 会发生什么 |
|---|---|
| 8 页 → 3 页（≈1:1） | 任何忠实产物都是压缩，读起来必然像翻译。无论怎么写都救不回来 |
| 50 页 → 3 页（≈17:1） | 模型被迫做取舍，"编辑感"自动出现 |

所以第一步永远是 `page_map.py` 定正文页数 → 定档位（≤10 页→2 / 11–30→3 / >30→4）→ 不匹配先回问。
**别用文笔去补算术的窟窿。**

## 二、什么配进这几页

优先选取（这些才是读者点开、转发的理由）：

- **明显的市场预期差**——市场与分析师看法相左之处，往往是整份报告最有价值的一条
- 能**改变投资者认知**的结论；最关键的投资逻辑、产业趋势或公司判断
- 传播性强、可讨论的数据 / 预测 / 观点；能直接回答"**这事为什么现在值得关注**"
- 趋势拐点，增长 / 盈利 / 估值 / 行业格局的变化；与当前市场热点强相关的内容
- 报告里最值得单独放大的那张图、那个数、那个事实

主动舍弃：大段背景介绍、免责声明、常识描述、重复论述、方法论细节、没有阅读吸引力的内容。

**舍弃 ≥3 条是硬要求**，写进大纲并说明为什么舍。一条都不舍 = 你没在选材。

## 三、主线怎么找（最难、也最值钱的一步）

主线 = **一句原文没有直说、但读完全篇才能说出口的判断**。它不是摘要压缩，也不是英文标题的中译。

自检三问：

1. 这句话在原文里能一字不差地找到吗？能找到 → 那是摘要，不是主线。
2. 去掉这句话，成品还成立吗？成立 → 说明它没在组织内容，重找。
3. 读者只记住这一句，值不值？不值 → 换。

**真实例子（9.01 大摩锂业，51 页 / 正文 8 页）**：

| | 实际做出来的（失败） | 应有版本 |
|---|---|---|
| 大标题 | 锂价，能涨一波吗？（英文标题直译） | 两颗雷要同时爆才翻短缺——反弹是战术机会，不是新周期 |
| 主线 | 无独立主线，封面"一句话说清"是原文摘要压缩 | 市场按 2027 小过剩定价；大摩算过，翻回短缺要"枧下窝不复产 **且** 津巴布韦不加配额"两条**同时**成立（88−60=28 kt，单靠一条翻不了负）；中期路径仍向下 |
| 页数 | 3（指令写死） | 2（正文 8 页） |
| 保留 | 供给两颗雷、EV、ESS 出货表、库存卡、成本曲线、价格路径——**全部** | 双条件算术卡、津巴布韦硫酸锂产能 <1/3 表、成本曲线 +150%、价格路径条 |
| 舍弃 | 无 | ESS 出货预测表、库存卡、EV 出口段（压成一行或删） |

⚠️ 关键教训：**那条正确的主线，模型自己在交付总结的自查环节里写出来了**——"2027 翻回短缺需两条件同时
成立"就是它自己算的。素材一直在，缺的只是一个**要求它先选再写**的步骤。所以别指望"想得更深"，
要靠"先出大纲"这个动作把已经想到的东西提到前面来。

## 四、有没有预期差，是可以说没有的

**没有预期差就不要造冲突。** 直接写「本篇无预期差，按信息整理做」——这是泄压阀，用它比硬凑一个
"市场错了"的假冲突体面得多。四类报告的变体：

| 报告类型 | 主线通常长什么样 | 版面重心 |
|---|---|---|
| 个股深度 / 首次覆盖 | 市场在错误定价某一个变量 | 估值卡 + 分歧带 + 目标价刻度 |
| 行业 / 主题 deck（>30 页） | 一条产业链上的瓶颈转移 | 大图 + 排名条 + 跨页重组 |
| 宏观 / 政策跟踪 | 官方口径 vs 还原口径的差 | 口径对照表 + 进度刻度尺 |
| 周报 / 图册（正文短、附录长） | **通常只有一条算术结论** | 2 页，一张核心图 + 一张算术卡 |

第四类就是 9.01 那种：正文短、图册长。**这类默认 2 页，且默认只做"图表 + 关键结论"。**

## 五、文字风格（杜绝 AI 腔与研报腔）

专业、克制、信息密度高。**直接给事实和结论，别铺垫。**

禁用：「本报告主要介绍了……」「报告首先分析了……随后讨论了……」「综上所述……」「值得投资者重点关注……」
禁用词：赋能 / 闭环 / 抓手 / 护城河（除非原文本来就这么写）。

- 差：报告认为 AI 数据中心的发展将推动电力需求增长。
- 好：AI 基础设施投资正从算力约束转向电力约束——决定下一阶段扩张速度的，可能不再是 GPU，而是电网接入。

## 六、覆盖率怎么看（只报数，不判定）

`coverage_report.py` 会给出：正文页覆盖率、被引用的不同页、前三页引用占比、标题直译标记、页数档位匹配。

**"前三页占比"不设门禁。** 实测五份成品从 14% 到 86%，与满意度无关：被接受的批次里有 86% 的，
被打回的只有 48%。投行研报摘要在前、图册在后，前三页占比高是**输入性质**，不是失败信号。
真正的门禁是三道是非题（标题直译？章节照原文？有没有原文没有的主线判断？）加一条页数算术。

**「未被引用的正文页」要逐页交代（2026-09-10 用户确立，此后每篇都做，之前的成品不追溯）**：
coverage_report 会打印这份清单，对它**逐页写一句「这页是什么内容 / 为什么没进成品」**。
仍然不设阈值、不判 FAIL——它的作用不是打分，是**证明你真读了**：没读过的页，说不出它是什么。
写不出来的页，回去读那页再动笔。舍弃理由可以和大纲里的「舍弃 ≥3 条」重合，重合就直接引用大纲那条。
注意：披露区与图册区不进这份清单，它们本来就不该读。
