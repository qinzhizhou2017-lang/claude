## 云端环境（2026-09-23 实测）

- 跑过 `云端/setup.sh` 后，四个脚本都能跑通；两份母本用 `render_pdf.py` 渲染，页数分别是 12 页、3 页，都对。
- 母本字体栈写的是 Mac 字体（PingFang SC / Songti SC），容器里没有。`setup.sh` 装了 Noto Sans / Serif CJK，
  并用 fontconfig 把这两个名字映射过去，母本不用改。成品字形与 Mac 版接近但不完全相同。
- Chromium 生成 PDF 时把 Noto CJK 嵌成 Type3，所以用 pypdf 列字体会显示 `None`。这是正常现象，不是掉字。
- 云端没有 Claude Code 桌面沙箱的问题，`render_pdf.py` 不需要 `dangerouslyDisableSandbox`。
