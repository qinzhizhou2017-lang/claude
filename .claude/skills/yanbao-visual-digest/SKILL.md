# 研报可视化精华版（7.26）

把一份长研报重新**编辑**成一份投资者愿意看完、愿意保存、甚至愿意转发的 4 页以内精品金融内容。
目标不是复述，也不是逐页压缩，而是从整份报告里筛出**最具信息价值、投资启发性、市场关注度与阅读吸引力**
的内容，用专业编辑和视觉手法重新组织，让读者在几分钟内抓住这份研报最值得关注的核心结论。

成品参照 **Institutional Research × Premium Financial Media** 的质感（高盛 / 摩根士丹利 / 摩根大通 /
Bloomberg / The Economist / FT Visual Storytelling），高级、极简、专业、高信息密度、强视觉层级，
适合手机阅读与微信转发。**不要**做成 Word 报告样式，也**不要**做成廉价营销 PPT。

---

## 工作流（照此顺序）

0. **装环境**：`bash scripts/setup.sh`（装 pymupdf / pillow / pyzbar / 思源 CJK / libzbar）。
   Inter 与 Fraunces 已随 `assets/fonts/` 打包，无需下载。若要更高级的 Latin 字体可再下（见下）。
1. **通读全文**：`python scripts/extract_pdf_text.py <报告.pdf>` 导出**每一页**文本。
   **必须读完整份报告再筛选**，绝不允许只看首页 / Executive Summary / 目录 / 前几页就总结。
   若某图表的数值只在图里、文本抽不出，用 pymupdf 把该页渲染成图片再读（`doc[i].get_pixmap(dpi=140)`）。
2. **筛选与定调**：按下方「内容筛选」标准，主动判断哪些内容值得进最终成品；
   找出**唯一的核心叙事 / 最大预期差**，整份精华版都围绕它展开。宁可少而精，不要为覆盖完整而堆砌。
3. **搭版式**：以 `assets/template.html` 为骨架，替换其中内容，保留设计系统（CSS、组件、配色、字体）。
4. **渲染**：`bash scripts/render.sh <你的.html> <输出.pdf>`（无头 Chromium → A4、4 页、背景色打印、字体内嵌）。
5. **核对与验收**：逐一比对每个数字与原报告；把每页栅格化成图片肉眼检查排版；
   用 `scripts/crop_qr.py` / pyzbar **解码验证二维码**在最终 PDF 里仍可扫。见下「验收清单」。
6. **交付**：把 PDF 发给用户（`SendUserFile`）。默认不建 PR，除非用户明说。

> 每一步为什么重要都写在下面。今天的模型很聪明，理解了「为什么」才能在具体报告上做出好判断，
> 而不是机械套模板——所以请把这份技能当作**方法**，而非填空表。

## 一、内容筛选：什么才配进这 4 页

优先选取（这些才是读者点开、转发的理由）：
- **明显的市场预期差**——市场与分析师看法相左之处，往往是整份报告最有价值的一条。
- 能**改变投资者认知**的结论；最关键的投资逻辑、产业趋势或公司判断。
- 传播性强、可讨论的数据 / 预测 / 观点；能直接回答「**这事为什么现在值得关注**」。
- 趋势拐点、增长 / 盈利 / 估值 / 行业格局的变化；与当前资本市场热点强相关的内容。
- 报告里最值得单独放大的图表、数据或事实。

主动舍弃：大段背景介绍、免责声明、常识描述、重复论述、方法论细节、缺乏阅读吸引力的内容。

**找到那条主线**。示例（供体会，不要照搬）：一份电池龙头的业绩点评，真正的钩子往往不是「业绩符合预期」，
而是「**市场在卖错的数字**」——市场盯着下滑的毛利率恐慌，而衡量护城河的单位净利润其实四年没变。
先找到这种一句话能讲清、又有预期差的核心冲突，再决定版面。

---

## 二、准确性（最高优先级）

- 所有数字、公司名、预测、时间、百分比、价格目标、评级、市场规模、财务数据，**一律以原研报为准**。
- **不得**自行补充报告里没有的数据或结论；**不得**把推测包装成原报告观点。
- 每个重要数字都确认**单位、时间周期、比较基准**（同比 / 环比 / 半年 vs 全年）。
- 区分**历史数据 / 预测数据 / 分析师假设**，不得混为一谈（如「调整后净利」与「报告净利」要标清口径）。
- 完成后做一次**交叉核对**：数字、公司名、时间、单位、结论逐条对回原文。

---

## 三、篇幅与页面结构（默认 4 页，按报告灵活调整）

A4 竖版（210×297mm），**严格 4 页以内**。不靠极限缩字号 / 压行距 / 堆字来凑页数；每页有明确主题与视觉中心。

- **P1 封面**：报头 + 眉标（公司 / ticker / 事件）+ **重新提炼的中文大标题**（别照搬英文原标题）+ 副标题
  + 「核心判断」条 + 3 张核心数字卡 + 2 张催化剂条 + 目录条。
  封面要让读者秒懂：**这份研报讲了什么？为什么现在值得看？对投资者意味着什么？**
- **P2 核心投资逻辑 / 最大预期差**：核心观点 callout + **主图（标题直接写结论）** + 佐证面板
  （历史类比框、同业对比）+「投资含义」条。用「核心观点 + 数据证据 + 投资含义」结构，别写连续大段。
- **P3 关键数据 / 行业趋势 / 公司机会**：KPI 数字行 + 一张有表达价值的图（份额攀升 / 趋势 / 对比 / 时间轴 /
  产业链）+ 资本回报条 + 新增长极卡片。不要为了「可视化」而做没有意义的图表。
- **P4 投资结论 / What Matters Next + 二维码**：结论条 + 估值卡（A/H）+ 预测数字条 +
  「会强化逻辑 / 会挑战逻辑」两栏 + 重点跟踪 chips + 品牌化二维码卡 + 免责声明。

---

## 四、文字风格（财经媒体腔，杜绝 AI 腔）

专业、克制、信息密度高、有投资逻辑。**直接给事实和结论**，别铺垫。

禁用这类机械研报腔：「本报告主要介绍了……」「报告首先分析了……随后讨论了……」「综上所述……」
「值得投资者重点关注……」。标题在忠于原意的前提下重新提炼成有传播力的中文。

**示例**
- 差：「报告认为 AI 数据中心的发展将推动电力需求增长。」
- 好：「AI 基础设施投资正从算力约束转向电力约束——决定下一阶段扩张速度的，可能不再是 GPU，而是电网接入。」

---

## 五、视觉设计系统（在 `assets/template.html` 里已实现，改内容、留结构）

- **版式**：整页暖色纸底铺满，footer 固定在底；主体用 `.main{display:flex;flex-direction:column;
  justify-content:space-between}` 自动撑满一页高度，避免底部大片留白。
- **字体**：思源宋体 `Noto Serif CJK SC`（标题）+ 思源黑体 `Noto Sans CJK SC`（正文）
  + `Inter`（Latin/数字，用 tabular-nums）+ `Fraunces`（大号展示数字，高对比衬线）。
  bundled woff2 用 `@font-face` 引；思源用系统名引（`setup.sh` 里装）。
- **配色（“恐惧 vs 强大”体系）**：暖纸 `#F4F1EA`、墨 `#17191E`、藏青 `#1B2440`（结构/权威）、
  信号红 `#C0271C`（市场的恐惧 / 强调）、深绿 `#12705C`（基本面的强大 / 正向）、金 `#9A7B3F`（极细的高级点缀）。
  红 = 市场在怕的，绿 = 底层其实很稳，藏青 = 机构框架——配色本身呼应叙事。
- **层级**：一级=核心结论 / 大数字 / 主标题；二级=数据证据 / 图表 / 逻辑；三级=解释 / 来源 / 注释。
  正文避免连续长段；**每页至少一个明显视觉锚点**（大数字 / 一句判断 / 趋势图 / 对比 / 数据卡 / 时间线）。
- **图表**：手搓 SVG / HTML（模板里有：双线对照、水平条形、哑铃式份额攀升、KPI 卡）。
  **标题直接表达结论**、重点数据明显、坐标单位清晰、删无关元素、**图下必留数据来源**。
  某观点不适合做图，就用大数字 / 数据卡 / 排版强化，别硬做图。

模板里可直接复用的组件（class）：`.mcard` 核心数字卡、`.callout(.green/.navy)` 观点条、`.panel` 面板、
`.bars` 水平条形、`.dumb/.drow` 哑铃攀升图、`.kpirow/.kpi` KPI 行、`.capband` 资本回报深色条、
`.vec` 增长极卡、`.valcard` 估值卡、`.fcast` 预测条、`.watch` 强化/挑战两栏、`.qrcard` 二维码卡。

## 六、二维码（必须 100% 可扫）

- 用**用户提供的原二维码**，绝不修改其定位点 / 编码结构 / 做影响识别的艺术变形。
- 若二维码是用户**贴在对话里**（非文件），从会话日志抽取：`python scripts/extract_qr.py`
  （默认自动找最新 session JSONL；也可传入路径）。
- 用 `python scripts/crop_qr.py <in.png> <out.png>` **裁掉外围 logo / 说明文字，只留二维码 + 充足静区**
  （脚本会加 ~15% 白边并用 pyzbar 验证裁切前后解码一致）。再把它放进 `.qrcard` 品牌卡里，
  配简洁中文 CTA（如「读懂全球投行的核心观点 / 微信扫一扫」），字体配色与整份 PDF 统一。
- 二维码不得过小（模板给 ~40mm）。渲染出 PDF 后，**用 pyzbar 在 150dpi 与 300dpi 各解码一次**确认可扫。

## 七、验收清单（交付前逐条过）

- [ ] 是真的提炼了最值得读的部分，而非平均压缩所有章节？有没有更有传播/投资价值的点被漏掉？
- [ ] 每个重要数字都与原研报一致（单位 / 周期 / 口径核对过）？没有原文不存在的推断？
- [ ] 标题准确又有吸引力？4 页内仍留有舒适阅读空间（没有靠缩字硬塞）？
- [ ] 图表真的帮助理解，且都标了来源？每页都有清晰视觉锚点？
- [ ] 二维码清晰、经 pyzbar 解码验证可扫、并与整体设计协调？
- [ ] 明确区分了「研究来源（投行）」与「整理方 / 公众号品牌」，附了免责声明（数据以原报告为准、不构成投资建议）？

## 文件

- `assets/template.html` —— **已填好内容的 4 页范例**（宁德时代 2Q26），承载完整设计系统。
  用法：**保留 CSS 与组件结构，替换文字 / 数字 / 图表数据**；`<img src="qr.png">` 与 `fonts/` 均为相对引用。
- `assets/fonts/Inter-var.woff2`（可变，100–900）、`Fraunces-600.woff2`（展示衬线）。
- `scripts/setup.sh` —— 一次性装依赖与思源 CJK 字体。
- `scripts/extract_pdf_text.py` —— 导出报告 PDF 全文（可选起止页）。
- `scripts/extract_qr.py` —— 从 Claude 会话 JSONL 抽取用户内联粘贴的图片（二维码）。
- `scripts/crop_qr.py` —— 干净裁切二维码（留静区）并 pyzbar 验证解码。
- `scripts/render.sh` —— 无头 Chromium 把 HTML 渲染成 4 页 A4 PDF（自动探测 chromium 路径）。

> 需要更高级的 Latin 字体时（Inter 已够用），可经 Google Fonts 代理下载：
> `curl -A "Mozilla/5.0" "https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800;900"`，
> 再取其中 `latin` 子集的可变 woff2 即可。
