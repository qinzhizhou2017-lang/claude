01 · 现金与融资
主动让出惰性利差，换取 AUM

闲置现金收益与融资利率是 Agent 最先比价的项目。建议默认开启现金自动理财（货基）、分档公示利率，把“利差收入”转化为“资产留存”。

02 · 会员与积分
积分价值不能靠“过期沉淀”

报告把积分 breakage 列为惰性租。积分体系应以真实兑换价值与行为激励为核心，考核兑换率而非沉淀率，避免被 Agent 一次性“薅平”。

03 · 资讯与社区
从“流量位”转向“权威数据”

注意力租衰减最慢但终将衰减；矩阵中“权威数据与核心记录”仍可防御。应强化独家研报、持仓关联解读、社区真实交易数据等 Agent 无法生成的内容。

04 · Agent 接入
提前布局 Agent 可调用能力
