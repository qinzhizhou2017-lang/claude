# 第一章 研究问题、方法与证据边界

## 1.1 研究问题与时间范围

本研究要回答的问题是：**当人工智能持续降低知识生产、软件开发、信息分析和流程执行的成本时，未来三至五年会出现哪些新的需求、瓶颈和责任？其中哪些能形成有人付费、能持续交付、有一定进入壁垒的商业活动和职业分工？个人可以通过什么具体行动提前获得进入这些机会的能力？**

- **研究执行期**：2026 年 10 月 19 日至 10 月 20 日。证据检索截止于 2026 年 10 月 20 日；报告中“截至目前”均指这一日期。
- **预测区间**：2027 年 1 月至 2031 年 10 月。以 2029 年底为三年观察点，以 2031 年为五年观察点。
- **地域范围**：以美国和中国为主，涉及欧盟、日本、印度、菲律宾等与委托人可进入性相关的市场。
- **不预设立场**：本研究不预设“人工智能必然替代全部知识工作”。替代程度作为待验证的问题，被拆成任务自动化、岗位缩减、岗位重构和新增岗位四种效应分别检验（第三章）。

“具体程度”以 FDE 为参照：一个候选方向必须具体到“谁、为什么、为哪个任务付钱”，例如“为人身伤害律所按件生成医疗记录摘要与索赔函”，而不是“AI＋法律”。

## 1.2 机会的五种性质

所有候选方向都被归入以下五类之一（可注明次要属性），类别不能混用：

| 代码 | 类别 | 判定标准 |
|---|---|---|
| T1 | 新产业或新细分市场 | 出现相对独立的客户需求、预算科目、专门供应商与产业分工 |
| T2 | 新商业模式 | 既有需求的交付方式、收费方式或成本结构发生实质变化 |
| T3 | 新职业或新组织职能 | 企业为一组新的、持续存在的职责配置专门人员和预算，并跨多家企业扩散 |
| T4 | 既有行业或职业升级 | 工作内容变化明显，但尚不足以认定为新产业或新职业 |
| T5 | 短期过渡机会 | 主要来自当前技术缺陷、实施困难或信息差，可能随技术进步迅速消失 |

此外，用“新颖度”区分真正的新需求与改名：N0 改名（职责与既有岗位基本相同）、N1 既有需求显著扩张、N2 既有职能重构（相当比例的核心任务是新的）、N3 真正新需求（没有 AI 就没有这项需求）。第四章用 FDE 的核实把这些定义细化为八条可检验的标准。

## 1.3 多 Agent 研究流程

本研究在可调用多 Agent 的环境中执行，采用 1 名主协调 Agent 加 12 名专业 Agent 的真实分轮流程。每名专业 Agent 是独立运行的子 Agent，有各自的上下文和检索记录，产出写入共享目录，由主协调统一汇总、裁决。分工如下：

| 编号 | 研究领域 | 第二轮负责的重点方向 |
|---|---|---|
| A01 | 技术能力与成本 | D4 AI 评测、规格与验收 |
| A02 | 劳动经济与岗位变化 | D5 专家数据与模型训练反馈 |
| A03 | FDE 与新型职业 | D1 FDE 与 AI 部署工程 |
| A04 | 企业采购与预算 | D10 组织重构服务 |
| A05 | 基础设施与系统集成 | D6 Agent 安全、身份与权限治理 |
| A06 | 安全、评估与治理 | D7 AI 合规与治理服务 |
| A07 | 垂直行业与价值链 | D8 垂直“服务即软件”与按结果交付 |
| A08 | 组织重构与专业服务 | D3 Agent 运营与人机兜底层 |
| A09 | 创业模式与单位经济 | D9 AI 单位经济工程 |
| A10 | 区域差异与可进入性 | D2 AI 落地交付服务的新形态 |
| A11 | 数据核验与预测建模 | 关键数字核验与市场规模估算 |
| A12 | 反方审查 | 第三轮审查全部重点方向 |

执行顺序为：

1. **R0 统一定义**（主协调）：研究问题、五类机会与新颖度尺度、证据等级、标注规则、文件格式，以及 10 条初始研究假设 H1–H10。
2. **R1 建立证据库**（A01–A12 并行）：每名 Agent 按专属问题检索，提交备忘录（研究问题、核心发现、证据出处、不确定性、对假设和其他 Agent 结论的质疑）、来源台账和关键数据卡。R1 共产出 12 份备忘录（约 9.7 万汉字）、700 条来源、290 张数据卡。
3. **R1 汇总**（主协调）：采纳 Agent 提出的 7 项框架修订，对 H1–H10 作阶段性裁决，合并形成 33 个候选方向，按统一标准选出 10 个重点方向。
4. **R2 深度研究**：10 名 Agent 各负责一个重点方向，按统一的 13 项问题模板研究，并必须点名回应至少 3 条其他 Agent 在 R1 提出的质疑；A11 同步核验关键数字并做市场规模估算。
5. **R3 反方审查与数据复核**：A12 对全部重点方向做反方审查，A11 复核进入正文的关键数据与估算。
6. **R4 裁决与整合**：主协调逐条裁决哪些判断被保留、修正或否定，统一定义、消除重复、解决证据冲突，撰写最终报告。

第六章 6.5 节列出交叉审查后被保留、修正和否定的主要判断；附录 E 记录每轮的真实执行情况，包括中断与续接。

## 1.4 证据体系

**证据等级。**E1：官方统计、法律法规与监管文件、企业财报与证券监管文件、政府采购与招投标公告；E2：一手产品文档与价格页、真实招聘职位原文、公开合同；E3：学术论文、披露样本与方法的调查研究；E4：行业研究机构预测、方法披露不充分的咨询与投资机构报告、主流媒体报道；E5：企业宣传中的效果主张、个人博客、未披露方法的榜单。关键结论至少需要一项 E1–E3 证据或两项相互独立的 E4 证据；多家媒体转载同一材料只算一个来源；企业宣传只能证明“企业提出了某项主张”。

**案例状态。**C1 宣布或试点、C2 签约、C3 正式部署、C4 实际付费、C5 持续续约或扩张，另设 C-R 表示撤回或缩减。融资和客户 Logo 不能证明 C3 以上。

**市场规模口径。**M1 已实现收入（再细分为 M1a 确认收入、M1b 合同或订单口径如 ARR/ACV/业务簿、M1c 年化外推）、M2 企业支出、M3 融资额、M4 潜在市场、M5 预测市场规模。不得以 M3 代替需求，不得以 M4、M5 代替实际收入，模型层与应用层收入不得相加。

**招聘数据。**区分招聘广告数量、实际招聘人数与净新增就业；写明平台、范围和是否去重。本研究引用的 FDE 等岗位增长数据全部是招聘广告数。

**判断标注。**报告中的关键判断标注为【事实】（有可核验资料支持）、【推断】（由事实推导，须给出推导与替代解释）或【预测】（依赖特定假设，须写明条件、时间与失效情形），并给出高、中、低三级置信度。缺乏校准基础时不给出精确概率。

**引用方式。**正文中的方括号编号（如 [R012]）对应附录 A 参考文献；附录 A 同时保留每条来源在 Agent 台账中的原始编号，便于追溯。标注“本文测算”的数字为本研究计算，计算过程见附录 C。

## 1.5 能力边界与证据缺口（必读）

本研究的证据质量受到三项环境限制，读者需要据此理解全部结论的置信度。

**第一，只能使用网页检索，无法打开原文。**研究环境中的网页抓取工具对所有域名都 DNS 解析失败，命令行直连外网也被代理拒绝。因此，全部证据都来自检索工具返回的标题、链接和对页面内容的摘要，而不是逐字阅读原始网页、PDF 或数据库。参考文献中的“访问状态”一栏如实标注了“检索摘要级”“多检索式复核”或“未能确认”。为降低摘要误差，关键数字要求用两个以上不同检索式复核，并尽量把检索限定在原始发布方的域名上；仍可能存在摘要把不同来源的数字混写的情况，凡发现的都已在正文或附录 D 中注明。

**第二，检索配额与平台用量上限。**全体 Agent 共享的检索配额约 200 次，第一轮并行时被迅速耗尽，多名 Agent 未达到预定检索量；研究过程中还两次因平台用量上限中断，经续接后完成。由此造成的证据缺口主要有：中国劳动力市场的招聘与薪酬数据、中国企业 AI 采用的官方统计、私有化部署成本、幻觉率与 Agent 工具使用基准、部分企业的原始财报文本。这些缺口影响的结论在正文中被下调了置信度，附录 D 列出了完整清单。

**第三，无法访谈。**本研究没有进行任何访谈或问卷，报告中不存在访谈引语。所有关于“企业为什么付费”的判断，都来自公开文件、价格页、职位描述和财报。

在这些限制下，本报告的结论应被理解为：**基于 2026 年 10 月可公开检索的证据，对机会结构所做的、标明了置信度的判断**。它适合用来决定“先验证什么、先放弃什么”，不适合直接作为投资或辞职决策的唯一依据。第七章的行动方案因此以低成本验证为核心设计。
