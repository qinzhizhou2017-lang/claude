01分化与涨价逻辑Old Memory Diverges
老内存与主流内存持续分化：主流大厂把产能转向 HBM/先进制程，退出传统产品，让 DDR4、SLC NAND、NOR flash 的供给持续收紧、涨价延续至 4Q26、甚至 1Q27。
涨价三重奏 · Pricing Surge
DDR4
+50% · 3Q
4Q 再涨双位数；需求从服务器扩散到消费电子，比主流内存更强
SLC NAND
+50%+ · 3Q&4Q
产能受限、晶圆不愿分给传统品；延续至 2027，MLC→SLC 迁移续撑
最高信念
NOR flash
+30–40% · 3Q
4Q 再涨、动能延至 1H27；工业 / 汽车 / 网络 / 边缘 AI 需求支撑
为什么"没有长约"反而好？
投资者担心缺少长约(LTA)=周期不稳；但大摩的逻辑正相反——
1
主流厂退出，供给收紧
三星 / 美光 / 海力士转向 HBM，退出 DDR4 / 传统制程
2
无固定价长约 = 现货更充分
价格随行就市，涨价传导更彻底
3
周期比预期更长
供给紧张延续到 2027；MLC→SLC 迁移撑 1H27
